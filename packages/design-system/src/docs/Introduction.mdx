# Veyra Design System

A token layer over [Ant Design](https://ant.design) v6. Ant Design supplies the
components; this package supplies the decisions — colour roles, type scale,
spacing grid, elevation, motion — and translates them into an antd `ThemeConfig`.

## The one rule

Tokens flow in one direction:

```
palette.ts  →  semantic.ts  →  createTheme.ts  →  antd components
(raw ramps)    (roles)         (ThemeConfig)
```

Reach past a layer and the theme stops being swappable. In practice:

- **Never** import from `tokens/palette` outside `tokens/semantic.ts`. Hex values
  belong in exactly one file.
- Prefer a **role** (`colors.textSecondary`) over a ramp step (`neutral[7]`). The
  role survives a rebrand; the ramp index does not.
- If a component needs a colour that has no role yet, add the role — don't inline
  the hex.

## Getting started

```tsx
import { ThemeProvider } from '@veyra/design-system';

createRoot(el).render(
  <ThemeProvider>
    <App />
  </ThemeProvider>,
);
```

`ThemeProvider` defaults to `system`, tracks the OS preference live, persists the
user's choice to `localStorage`, and mounts antd's `<App>` so `message`,
`notification` and `modal` inherit the theme too.

## Reading tokens in a component

```tsx
const { colors, space, shadows } = useVeyraTokens(); // our semantic layer
const token = useAntdToken();                        // antd's resolved aliases
```

Use `useAntdToken()` when styling *around* an antd component — it returns every
alias antd is actually using, after its light/dark algorithm has run. Use
`useVeyraTokens()` when the role name is what matters.

## Why the wrappers exist

Each wrapper earns its place by adding a distinction antd leaves open:

- **`Button`** — antd v6 can express one look through `type`, `color`, `variant`,
  `danger` or `ghost`. `intent` names the *job* so an intent maps to exactly one
  appearance.
- **`Card`** — adds `elevation` from the shadow scale, resolved per mode. A shadow
  tuned for white is invisible on near-black.
- **`Stack`** — accepts only spacing-token names for `gap`. Arbitrary pixel gaps
  are how a 4px grid quietly erodes.
- **`ThemeToggle`** — three states, not two. A binary toggle can't say "follow
  the OS", so either choice would silently end system sync.

Anything antd already does well is re-exported unchanged — import it from `antd`
directly.

## Accessibility

Contrast is treated as a property of the tokens rather than something checked
afterwards. **Foundations → Contrast** measures every pairing the system relies
on, live, against antd's *resolved* tokens — the light/dark algorithm shifts the
seeds, so auditing the input would report numbers nobody ever sees.

`npm run a11y` sweeps axe-core over every story in both themes and exits
non-zero on any violation.

## Changing the brand

Edit the `veyra` ramp in `tokens/palette.ts`. Every seed token, alias, component
override and both modes follow from it. Re-run `npm run a11y` afterwards — the
ramps are tuned to specific contrast thresholds.
